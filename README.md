# pizza-calculator-apple-shortcut
This is my Pizza Calculator shrinked down to an Apple 
https://www.icloud.com/shortcuts/227f2b0038a24066a43c4c7ef15b28b9

Please use this link to use this Shortcut. 

The Shortcut is used to calculate the ingredients for pizza dough related to the amount of flour used.
If you run this Shortcut you are asked to enter the amount of flour used (in grams).
The entered amount is used to calculate the correct amount of the other ingredients.
You can see the "standard" recipe in the "code".

The "code" has a block to configure a scan. I added an NFC sticker to my kitchen for easy access to my calculator. 
You can do so too. Most EC-cards you don't need anymore will work fine too. Just set it up as an Automation in Shortcuts.

Have fun, save time and make yourself and friends happy with delicious Pizza
